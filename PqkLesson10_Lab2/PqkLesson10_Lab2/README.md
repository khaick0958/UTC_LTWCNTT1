# BaiThucHanh2 - ASP.NET Core MVC (.NET 10)

Project thực hành theo tài liệu, gồm Layout, Partial View, RenderBody, RenderSection, ViewComponent và quản lý sinh viên.

## Form Create/Edit đã chỉnh theo ảnh mẫu
- Name
- Email
- Password
- Branch (CE, IT, Business, English)
- IsRegular (checkbox)
- DateOfBirth (ngày giờ)
- Gender (Male/Female)
- Address (textarea)

## Chức năng
- Danh sách và tìm kiếm sinh viên
- Tạo sinh viên
- Sửa thông tin sinh viên
- Xóa sinh viên có xác nhận

## Chạy trên Visual Studio 2026
1. Cần cài .NET 10 SDK.
2. Giải nén ZIP vào thư mục mới.
3. Mở `BaiThucHanh2.csproj`.
4. Build > Rebuild Solution, sau đó Ctrl+F5.

Dữ liệu mẫu lưu trong bộ nhớ và sẽ được đặt lại khi khởi động lại ứng dụng. Mật khẩu chỉ là trường minh họa cho bài thực hành; không dùng cách lưu mật khẩu dạng rõ trong ứng dụng thực tế.
